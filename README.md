# みんなのToDoリスト

チームでToDoを共有・管理するためのシンプルなWebアプリです。
パソコンでもスマホでも同じデータをリアルタイムで見られます。

## できること

- タイトル・対応期日・対象者・メモを入力してToDoを作成
- 対応期日が近い順に一覧表示(1タスク=1行)
- 期日が近い/過ぎているタスクを色分け表示
- ToDoごとに「対象者」を複数選べて、対応した人が自分の名前の横にチェック
- 対象者全員のチェックが揃ったら「対応完了にする」ボタンで完了扱いに変更
  → いちいち「これやった?」と聞かなくても、一覧を見れば進捗がわかります
- メモ欄は自由記述で、報連相(進捗共有)にも利用可能
- メンバーは人数固定ではなく、アプリ内でいつでも追加・名前変更・削除が可能
- 「自分の担当のみ表示」「完了も表示」「検索」で絞り込み可能
- パソコン・スマホ(複数台)から同時に見ても、変更がリアルタイムで反映される

## セットアップ手順(最初に1回だけ)

データをパソコンとスマホ全員で共有するために、無料のFirebaseというサービスを使います。

### 1. Firebaseプロジェクトを作成

1. https://console.firebase.google.com/ にアクセスし、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 好きな名前(例: `yaritai-list`)を入力して作成
   (Googleアナリティクスは不要なのでオフでOK)

### 2. Firestore Database を作成

1. 左メニューの「構築」→「Firestore Database」を開く
2. 「データベースの作成」→ ロケーションを選択(例: `asia-northeast1` 東京)
3. モードは「本番環境モード」のまま作成してOK(ルールは後で設定します)

### 3. 匿名認証を有効化

1. 左メニューの「構築」→「Authentication」を開く
2. 「Sign-in method」タブ →「匿名」を選択して「有効にする」

### 4. Firestoreのセキュリティルールを設定

1. Firestore Database →「ルール」タブを開く
2. このリポジトリの `firestore.rules` の内容をコピーして貼り付け、「公開」

### 5. ウェブアプリを追加して設定情報を取得

1. プロジェクトの概要ページ →「</>」(ウェブアプリを追加)をクリック
2. アプリのニックネームを入力して登録(Firebase Hostingの設定はスキップでOK)
3. 表示された `firebaseConfig` の中身(apiKey, authDomain, projectId など)をコピー

### 6. 設定情報をアプリに貼り付け

このリポジトリの `firebase-config.js` を開き、`YOUR_API_KEY` などの部分を
手順5でコピーした内容に書き換えて保存してください。

```js
const firebaseConfig = {
  apiKey: "実際の値",
  authDomain: "実際の値",
  projectId: "実際の値",
  storageBucket: "実際の値",
  messagingSenderId: "実際の値",
  appId: "実際の値"
};
```

### 7. 公開する(GitHub Pagesの例)

1. GitHubのリポジトリ →「Settings」→「Pages」
2. 「Branch」でこのアプリをpushしたブランチ(またはmain)を選択して「Save」
3. 数分後、表示されるURL(`https://ユーザー名.github.io/リポジトリ名/`)にアクセス

このURLをパソコンのブックマークや、スマホのホーム画面に追加すれば、
アプリのようにいつでも開けます(スマホのブラウザ共有メニュー →「ホーム画面に追加」)。

## 使い方

1. 初回アクセス時、右上の「あなた」で自分の名前を選択(メンバーがいなければ先に「⚙ メンバー管理」で登録)
2. 「＋ 新しいToDoを追加」からタイトル・期日・対象者・メモを入力して保存
3. 対応したら、自分の名前のチェックボックスにチェック
4. 対象者全員のチェックが揃うと「✅ 対応完了にする」ボタンが出るので、最後の人が押すと完了になる
5. 完了したタスクは一覧から隠れます。見たい場合は「完了も表示」にチェック

## ファイル構成

- `index.html` — 画面のHTML構造
- `style.css` — 見た目のスタイル
- `app.js` — アプリのロジック(Firestoreとの通信・画面描画)
- `firebase-config.js` — Firebaseの接続設定(自分のプロジェクトの値に書き換える)
- `firestore.rules` — Firestoreのセキュリティルール(参考用)
- `manifest.json` / `icon.svg` — スマホのホーム画面に追加したときのアイコン設定
